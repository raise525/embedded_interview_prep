1. struct结构体： 不同成员放在不同地址，内存 = 所有成员大小之和（字节对齐）
```c
struct Example {
    char a;   // 1字节
    int b;    // 4字节
    char c;   // 1字节
};
这里的字节数就是 4*3 = 12
```
2. union联合体（共同体）：所有成员共享一块地址， 大小 = 成员中占内存最大的成员的大小

```c

// 最常用的（32/64位通用）
char     = 1字节   // 注意：不一定是8位！（但几乎都是）
int      = 4字节   // 面试默认说4字节，除非特指嵌入式
short    = 2字节
long     = 4或8字节  // 32位=4，64位Windows=4，64位Linux=8
long long= 8字节   // C++11起

// 指针（面试高频！）
int* p;  // 32位系统=4字节，64位系统=8字节

// 浮点
float    = 4字节   // 精度6-7位小数
double   = 8字节   // 精度15-16位小数

```
