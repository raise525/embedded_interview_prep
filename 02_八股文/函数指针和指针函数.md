# 函数指针 vs 指针函数

## 一句话区分
- **指针函数**：是一个函数，返回指针
- **函数指针**：是一个指针，指向函数

---

## 指针函数

### 定义
返回值为指针的函数

### 写法
```c
int* func(int a, int b);
```

---

## 函数指针

### 定义
指向函数的指针变量

### 写法
```c
int (*p)(int, int);
```

### 例子
```c
int add(int a, int b) { return a + b; }

int main() {
    int (*p)(int, int) = add;  // p指向add函数
    int result = p(3, 5);       // 调用，result=8
}
```
```c
int *p;      // 普通指针，指向int
int (*p);    // 同上，括号多余，等价于 int *p
int (*p)();  // 函数指针，指向返回int的函数
```
